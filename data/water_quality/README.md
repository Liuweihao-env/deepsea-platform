# 海水水质数据（pH / 溶解氧等）

**来源**：生态环境部 **国家海洋环境监测中心** · 《海水水质监测信息公开系统》
<https://ep.nmemc.org.cn:8888/Water/>

**为什么单独建这一份**：平台 9 项环境指标里，**溶解氧**和 **pH** 在 NMDC 台站数据里**没有**：

- NMDC 的「海水水质数据集」**全部是外国海域** —— CALCOFI（东太平洋）、GLODAPv2（全球）、
  HOT（夏威夷）、BAT（百慕大）、CARINA（大西洋/南大洋）、HELCOM（波罗的海）、
  Medatlas（黑海/地中海）……**一个中国的都没有**
- NMDC 的「北海海洋观测资料_浮标」（渤海浮标）是 **有条件共享、需数据申请**，不是免费下载
- → 这两项改从**生态环境部**的公开系统取

**下载方式**：**静态 JSON，无需登录**，直接 GET 即可
```
https://ep.nmemc.org.cn:8888/Water/water2017.json  ~  water2026.json
```

## 一、原始数据规模

**34 224 条监测记录**，2017 ~ 2026 年，四大海区：

| 海区 | 记录数 |
|---|---:|
| 东海 | 10 525 |
| 南海 | 9 667 |
| 黄海 | 8 026 |
| **渤海** | **6 006** |

每条记录 = **一个监测点在某个月的实测值**，字段：

| 原始字段 | 含义 | 平台字段 |
|---|---|---|
| `sea` / `province` / `city` | 海区 / 省 / 市 | — |
| `site` | 点位编码 | — |
| `lon` / `lat` | 经度 / 纬度 | — |
| `minitor_month` | 监测月份 | `month` |
| `pH` | pH（无量纲） | `ph` |
| `rjy` | **溶解氧** mg/L | `dissolved_oxygen` |
| `hxxyl` | 化学需氧量 mg/L | `cod_mn` |
| `wjd` | 无机氮 mg/L | `din` |
| `hxlxy` | 活性磷酸盐 mg/L | `active_phosphate` |
| `syl` | 石油类 mg/L | `petroleum` |
| `szlb` | 水质类别（一类/二类/…） | `water_class` |

## 二、🔴 怎么关联到我们的四个台站（**这一段很重要**）

**平台没有这批点位** —— 它们是生态环境部的近岸监测点，不是养殖现场。
所以按**最近监测点**关联：

> **取本平台台站半径 60 km 内的监测点，按月聚合求均值。**

| 台站 | 海区 | 关联点位数 | 最近点位距离 | 月度记录数 |
|---|---|:---:|---|:---:|
| **芝罘岛** | 渤海海峡 | 40 | **3.4 km**（SDH06011 山东·烟台） | 40 |
| **小麦岛** | 黄海 | 40 | **3.3 km**（SDH02013 山东·青岛） | 49 |
| **嵊山** | 东海 | 40 | **7.3 km**（D31YQ103 浙江·舟山） | 44 |
| **遮浪** | 南海 | 40 | **10.6 km**（GD1504 广东·汕尾） | 39 |

### ⚠️ 平台上必须写明三件事

1. **这是附近监测点的月度均值，不是养殖现场实测**
2. **显示点位距离**（JSON 里每个点都带 `dist_km`）
3. **月度不连续** —— 监测是分季节做的，有的月份没有数据（如小麦岛缺 2025-09）

> **我们不插值填补。** 缺的月份就空着，页面上显示断点 ——
> 按「不许编」的规矩，**宁可图上断一截，也不编一个看起来合理的数**。

## 三、每个文件里有什么

| 文件 | 说明 |
|---|---|
| `ZFD.json` / `XMD.json` / `SSN.json` / `ZLG.json` | 四个台的月度水质序列 |
| `index.json` | 索引 + 字段说明 |
| `raw/water<年>.json` | **原始文件原样保留**（2017~2026，溯源用，不要改） |

每条月度记录长这样：

```json
{
  "month": "2025-08",
  "n_points": 6,
  "ph": 7.903,          "ph_range": [7.79, 8.05],
  "dissolved_oxygen": 6.258,  "dissolved_oxygen_range": [5.42, 7.1],
  "cod_mn": 0.727,      "din": 0.126,   "active_phosphate": 0.005,
  "petroleum": 0.004,
  "water_class": "一类",
  "class_counts": { "一类": 5, "二类": 1 }
}
```

> 每个指标都带 `_range`（该月各点位的最小/最大值），
> 页面可以画成**均值线 + 波动带**，比单点值更有信息量。

## 四、怎么重新下载

```bash
python tools/parse_water_quality.py [JSON 所在目录]
```

下载原文件的命令（无需登录）：

```
https://ep.nmemc.org.cn:8888/Water/water2017.json
https://ep.nmemc.org.cn:8888/Water/water2018.json
...
https://ep.nmemc.org.cn:8888/Water/water2026.json
```

> 🔗 这个 `water<年>.json` 的规律是从页面 JS（`RealDatas.js`）里读出来的 ——
> 页面上那个筛选器（年份 / 海区 / 区域）其实就是**换一个 JSON 文件**，不是调接口。
