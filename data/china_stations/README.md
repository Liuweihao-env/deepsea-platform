# 中国近海台站观测数据（NMDC）

**来源**：国家海洋科学数据中心（NMDC）「中国台站观测数据」`dataSetId=4`
<https://mds.nmdis.org.cn/pages/dataViewDetail.html?dataSetId=4>

**为什么换源**：老师意见（2026-10-09 会上定，第 5 条）——环境站点换成**中国近海**。
原方案用 NOAA NDBC（美国墨西哥湾/阿拉斯加/夏威夷），场景不贴合。

**下载方式**：**必须注册登录**才能下载（官方 FAQ 第 5 条：「用户需要在登录的状态下才能下载数据」）。
→ 一次性下载 + 入库随仓库走，**不在运行时代码里抓取**，以此保住「零依赖、断网也能演示」的铁律。

### ⚠️ 关于「渤海」这一格 —— 必须如实说明

渤海与黄海的分界是 **【蓬莱角—老铁山角】连线**。
NMDC 的 14 个台站里 **没有任何一个在渤海内部**：

- 芝罘岛 37.6°N/121.4°E（烟台）—— 在连线**以东** → 黄海
- 老虎滩 38.9°N（大连）—— 也在**以东** → 黄海
- 小长山 39.2°N（长山群岛）—— 也在**以东** → 黄海

**水质数据独立印证了这一点**：烟台附近的监测点，海区字段写的是**「黄海」**。

**所以本平台在这一格的处理是：**

| 项 | 取什么 | 页面怎么标 |
|---|---|---|
| **海况水文** | **渤海海峡**的芝罘岛台站 | 标「**渤海海峡**」，并注明 NMDC 无渤海内部台站 |
| **水质（pH/溶解氧）** | **渤海内部**的监测点（东营片区） | 标「**渤海监测点**」（见 `../water_quality/`） |

> **两边都如实标注，不假装「渤海里有浮标」。**
> 芝罘岛在渤海海峡、是进出渤海的咽喉，地理上说得通 —— 但**说清就是渤海海峡，不冒充渤海内部**。

**数据范围**：**2024-07 ~ 2025-08**，逐时，共 **55 个文件 / 40 248 条记录**。

## 三、🔴 文件格式（**这一段很重要**）

### 官方依据

格式来自站点上的《中国台站观测数据格式说明》PDF（「数据文件格式说明下载」）。
官方给了三版：

| 版本 | 适用年份 |
|---|---|
| v1.0 | 2010 年前 |
| v2.0 | 2010 年起 |
| **v3.0** | **2011 年起 ← 本项目数据用这版** |

### v3.0 列定义（**照抄官方说明，不是反推的**）

定宽 **107 字符/行**，逐时，右对齐，**无表头**。

| 列(1起) | 字段 | 单位 | 本项目是否使用 |
|---|---|---|:---:|
| 1-15 | Station | — | ✅ |
| 16-19 | Date（日） | — | ✅ |
| 20-23 | Time（时） | — | ✅ |
| 24-29 | Lat. | 0.01° | ✅ |
| 30-36 | Long. | 0.01° | ✅ |
| 37-43 | Visibility 能见度 | km | ❌ 全期缺测 |
| 44-50 | **Air Temperature 气温** | ℃ | ✅ |
| 51-57 | **Wind Direction 风向** | ° | ✅ |
| 58-64 | **Wind Speed 风速** | m/s | ✅ |
| 65-71 | **Air pressure 气压** | hPa | ✅ |
| 72-77 | 6 小时降水量 | ml | ❌ 全期缺测 |
| 78-83 | **Sea Temperature 水温** | ℃ | ✅ |
| 84-89 | **Wind Wave Height 浪高** | m | ✅ |
| 90-95 | **Wind Wave Period 周期** | s | ✅ |
| 96-101 | Surge Height 风暴潮增水 | m | ❌ 全期缺测 |
| 102-107 | Surge Period 风暴潮周期 | s | ❌ 全期缺测 |

> **四个「全期缺测」的字段**（能见度 / 6 小时降水 / 风暴潮增水 / 风暴潮周期）
> 在全部 40 248 条里**一条有效值都没有**。JSON 里**不写这四个字段**（省体积），
> 但格式说明保留在此 —— 将来 NMDC 若开始提供，解析器改一行就能启用。
>
> 依据「**不许编**」的规矩，这四个字段的含义来自官方说明而非猜测，但仍然**不写进接口**。

### 时间与缺失值

- **时区**：北京时间（UTC+8）。已验证 —— 气温在本地 12~15 时最高、20~23 时最低，符合昼夜规律。
- **缺失标记**：官方说明写「9 means no observation」。实测出现三种写法，**一律按缺失处理**：
  | 标记 | 说明 |
  |---|---|
  | `9999.9` | 未观测 |
  | `999.9` | 未观测 |
  | `99.7` | 另一种缺失，**只出现在逐 3 小时的 08/11/14/17 时** |
- **静风**：风速为 0 时，气象标准把风向写成 **`C`（calm）**而不是角度。
  解析时 **风向置 `null`、风速保留 `0.0`** —— 这是**两件不同的事**，不能一起丢掉。
- **范围校验**：每个要素都设了合理区间，超范围一律判为缺失并上报，
  **不悄悄当成正常值用**。

## 四、怎么重新下载 / 重新解析

### 重新解析（改了解析器时用）

```bash
python tools/parse_nmdis.py [原始文件所在目录]
```

默认从 `C:\Users\38793\Documents\比赛\_nmdis_dl` 读 `XXXYYMM.txt`，解析后写入本目录，
并在 `raw/` 留一份原始文件（溯源用）。

### 重新下载（数据要更新时）

NMDC 的数据下载**不是普通直链**，流程如下（已实测跑通）：

1. 浏览器登录 <https://mds.nmdis.org.cn/>
2. 打开 <https://mds.nmdis.org.cn/pages/dataViewDetail.html?dataSetId=4>
3. 页面的「数据清单」由 `POST /service/sdm/front/DataGridValue/getValue` 提供，
   每行含一个 **32 位十六进制 UUID**（列 key `6019082b1d1941cf89375bf04055d455`）
4. 下载地址：
   ```
   /service/sdm/front/DataGridValue/downLoad?datasetId=4&gridId=4&id=<UUID>&access_token=<登录令牌>
   ```
5. **必须带登录令牌** —— 令牌是 `FToken` cookie（JWT），也可作为 `authorization: Bearer <token>` 请求头

> ⚠️ **在浏览器外直接下会 401**（`invalid_token`）—— 令牌似乎绑定了来源。
> 本项目用 Playwright 在**已登录的页面里**造 `<a download>` 点击完成下载。
> 脚本见 `tools/nmdis_list.js`（枚举 UUID）和 `tools/nmdis_getall.js`（批量下载）。
