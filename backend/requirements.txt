# 依赖清单
#
# ============================================================
#  本项目刻意「零第三方依赖」。
# ============================================================
#
# 后端 backend/server.py 只用 Python 标准库：
#     http.server / json / threading / urllib / mimetypes / webbrowser
#
# 前端 frontend/ 也不用构建（Vue 3 与 ECharts 已内置在 frontend/vendor/）：
#     不需要 Node.js，不需要 npm install，不需要 npm run build
#
# ------------------------------------------------------------
#  为什么这么定（不是偷懒，是硬约束，见 项目记录.md 1.5 节）
# ------------------------------------------------------------
#  R1 —— 11-14 现场没人会改代码，崩了没有第二次机会
#        所以：一键启动 + 离线自包含（11-05 环境冻结是救命硬线）
#
#  「少一层就少一个翻车点」：
#    有依赖 → 需要 pip install → 需要联网/镜像 → 可能装不上
#    有构建 → 需要 Node + npm → 可能版本不对 → 可能构建失败
#    零依赖零构建 → 有 Python 3 就能跑
#
# ------------------------------------------------------------
#  启动方式
# ------------------------------------------------------------
#    双击  启动平台.bat
#    或    python backend/server.py
#
# ------------------------------------------------------------
#  关于 FastAPI
# ------------------------------------------------------------
#  原计划写的是 FastAPI，实测环境里未安装且运行时只读，故改为标准库实现。
#  接口形状与 FastAPI 版本一致；若日后要换回，只需替换路由层，
#  数据生成与指令状态机可直接搬用。
#
#  若确实要装（可选，非必需）：
#      pip install fastapi uvicorn
#
# ------------------------------------------------------------
#  本文件故意保持为空依赖，勿随意添加。
# ------------------------------------------------------------
