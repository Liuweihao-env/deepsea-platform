### 1.3 四个已预留、归属待定的路由

> 这四页跨板块，**归属 10-05 会上定**。**菜单位与路由位我已经留好，定了不改结构就能挂上。**

| 路由 | 页面 | 为什么跨板块 |
|---|---|---|
| `/alarm` | 告警中心 | 灾害预警（结构安全）+ 投喂动作（智能）+ 鱼类异常（鱼类）都要进来 |
| `/handle` | 处置中心 | 所有处置动作走智能板块的指令状态机 |
| `/trace` | 追溯查询 | "哪条数据 → 命中哪条规则 → 结果如何"，答辩必答题 |
| `/config` | 参数配置 | 环境阈值由环境板块提，判断规则挂在结构安全的规则引擎上 |

### 1.4 数据来源标签的取值（**纪律 4，不许省**）

每个页面顶部必须显示来源标签，取值只有这 4 个：

| 标签 | 含义 | 样式 |
|---|---|---|
| `真实数据` | 来自真实设备/老师提供的数据 | 绿色 |
| `公开数据` | 来自公开数据集（TFBID / DeepFish / NOAA NDBC） | 蓝色 |
| `仿真数据` | 程序生成 | 橙色 |
| `演示数据` | 手工准备、用于演示 | 灰色 |

> **多个来源并存时全部列出**，例：`公开数据 · 仿真数据`。
> **主动标出来源是加分项** —— 用假数据装成真的，才是答辩时最容易被戳穿的事。

## 三、通用组件（我做，你不用重复做）

> **每个组件分三部分写清：放什么字段 / 有哪些状态 / 怎么交互。** 状态没写全，就会出现"数据断了页面白屏"。

### 3.1 数值卡 `StatCard`

| 项 | 内容 |
|---|---|
| **放什么** | 指标名（小字）· 当前值（大字）· **单位** · **数据来源标签**（小字） |
| **状态** | ① 正常 ② 数据缺失（值显示 `—`，灰色，右上角标"设备离线"）③ 可疑（值显示为黄色，悬停提示"疑似异常"）④ 过期（值变灰，显示"最后更新 12:03:45"） |
| **交互** | 悬停显示：完整字段名、更新时间、数据来源 |
| **不许省** | **单位**和**来源标签** —— 单位错一次三个板块一起错 |

![图 2　数值卡 StatCard 的字段与排布：指标名 / 当前值+单位 / 数据来源](组件图-数值卡.png)

### 3.2 时序曲线卡 `TimeSeriesChart`

| 项 | 内容 |
|---|---|
| **放什么** | 标题 · 坐标轴（X 时间 / Y 数值 + 单位）· 曲线（可多条）· 图例 · 阈值参考线（可选） |
| **状态** | ① 正常 ② 无数据（显示"暂无数据"占位，不要白屏）③ 只有单点数据（显示散点而非折线） |
| **交互** | 悬停显示该点数值与时间；点击图例可隐藏/显示某条曲线；支持框选缩放（可选） |
| **异常标记** | 可疑点在曲线上**叠加红色圆点**，与明细表的"风险等级"对应 |
| **实现建议** | ECharts `line` + `markPoint` 做红点 |

### 3.3 事件列表 `EventList`

| 项 | 内容 |
|---|---|
| **放什么** | 时间 · 事件类型 · 简要描述 · **等级色标**（正常/注意/风险 或 蓝黄橙红） |
| **状态** | ① 正常 ② 空列表（显示"暂无事件"）③ 加载中（骨架屏） |
| **交互** | 点击条目展开详情；分级筛选；**支持"查看触发依据"跳转**（追溯用） |
| **注意** | 这是**告警中心与各板块共用的组件** —— 你先按这个做，将来告警中心直接复用 |

### 3.4 时间窗切换器 `TimeRangePicker`

| 项 | 内容 |
|---|---|
| **放什么** | 快捷项：`当前` / `1 小时` / `6 小时` / `24 小时` + `自定义`（选年月日范围） |
| **状态** | ① 默认选中"当前" ② 自定义范围非法（结束早于开始）时禁止提交并提示 |
| **交互** | 切换后**所有**图表与表格同步刷新（不要只刷一张图） |

### 3.5 数据来源标签 `SourceTag`

| 项 | 内容 |
|---|---|
| **放什么** | 文字标签，取值见 1.4；多个来源全部列出 |
| **状态** | ① 单一来源 ② 多来源并列 |
| **位置** | 页面顶部（全局）+ 每个数值卡内（单指标） |

### 3.6 状态色阶 `StatusColor`（统一色彩语义）

| 语义 | 颜色 | 用在哪 |
|---|---|---|
| 正常 / 良好 | 绿 `#166534` | 状态灯、明细表标记 |
| 注意 / 可疑 | 黄 `#92400E` | 预警黄色级、可疑数据点 |
| 风险 / 故障 | 红 `#991B1B` | 红色预警、故障、异常点 |
| 信息 / 蓝色级 | 蓝 `#2F5496` | 蓝色预警、主色 |
| 无数据 | 灰 `#6B7280` | 缺失、禁用、离线 |

> **四级预警（蓝/黄/橙/红）按此扩展**：橙用 `#C2410C`。

### 3.7 细分组件（按需）

| 组件 | 用途 | 归谁用 |
|---|---|---|
| 数据明细表 `DataTable` | 秒级时间 + 站点 + 全指标 + 来源 + 质量等级 | 鱼类、环境 |
| 站点切换器 `SiteSwitcher` | 多站点切换 | 鱼类、环境、结构安全 |
| **指令状态机进度条** `CommandFlow` | 显示命令走到哪一步 | 智能（答辩重点） |
| 拉力/密度色阶图 `Heatmap` | 网衣拉力分布、鱼群密度 | 结构安全、鱼类 |
| 确认弹窗 `ConfirmDialog` | 下发命令前二次确认 | 智能、结构安全 |

## 四、页面模板（照它填，只换主内容区）

### 模板 A　「总览型」——数值卡 + 曲线 + 事件列表

**用在哪**：鱼类监测总览、环境海况、环境水质、结构安全总览、灾普分级预警

```
┌ 数值卡区：3–4 张 StatCard ──────────────────────────┐
├ 主图区（宽 62%）──────────┬ 侧栏（宽 38%）─────────┤
│ TimeSeriesChart           │ EventList              │
│ 双 Y 轴 / 多曲线           │ 或 状态灯列表           │
└───────────────────────────┴────────────────────────┘
┌ 操作条：[TimeRangePicker]        [手动触发按钮] ─────┘
```

### 模板 B　「明细型」——表格为主

**用在哪**：鱼类原始数据明细、环境原始数据明细、智能指令日志

```
┌ 筛选条：[时间范围] [站点] [等级/状态] ────────────────┐
├ DataTable（占满宽度，可滚动）────────────────────────┤
│ 时间(秒级) | 站点 | 指标1 | 指标2 | ... | 来源 | 质量  │
└ 底栏：[导出] 共 N 条 ─────────────────────────────────┘
```

### 模板 C　「总览大屏型」——多板块汇总

**用在哪**：总览大屏 `/overview`

```
┌ 全板块顶部指标条（每板块 1–2 个关键值）──────────────┐
├ 左：结构安全风险等级 ┬ 中：鱼群与环境趋势 ┬ 右：告警计 │
│                     │                    │ 数 + 最新  │
├ 底：设备状态汇总 + 能源保障摘要 ─────────────────────┤
└──────────────────────────────────────────────────────┘
```

> **总览大屏由各板块提供数据**，页面本身不属任何板块。取数走接口，不直接读别人内部数据。

### 模板 D　「控制型」——按钮 + 状态反馈

**用在哪**：鱼类仿真控制、环境仿真控制、智能自动投喂、智能补光、造故障工具

```
┌ 操作区：3–5 个按钮（主按钮 1 个，其余次要）──────────┐
├ 状态反馈区：当前状态 + 最近一次操作结果 + 时间 ───────┤
├ 日志区：最近 N 条操作记录 ───────────────────────────┘
```

> **控制型页面必须有二次确认弹窗**（尤其下发命令类）。**不允许一键直接对设备生效。**

## 五、跨板块只走接口（硬纪律）

| 规则 | 说明 |
|---|---|
| ❌ 不允许 | 直接去读别人板块的数据、直接调别人内部的函数 |
| ✅ 一律走 | 已经定义好的接口 |
| 为什么 | 接口是一条"**缝合线**"。有它，四个板块能缝成一件衣服；没它，就是一地碎布 |
| 好处 | 你可以随便改自己板块内部的实现，只要接口不变，别人不受影响 |

## 六、给你的三条落地要求

| # | 要求 | 为什么 |
|---|---|---|
| 1 | **先打通一条小路**：先在骨架里跑通"一个数据 → 一张曲线 → 一条告警" | 不要"等整个模块写完再联调"。8 个漂亮页面没有任何数据能流进去，演示时只能看不能用 |
| 2 | **每个页面都要有数据来源标签** | 纪律 4，也过不了队长验收 |
| 3 | **有异议现在提** | 骨架定稿后改结构，四个人的页面一起返工 |

### 你交页面时的自检

- [ ] 用的是上面 4 个模板之一，没有自己另起布局
- [ ] 页面顶部有数据来源标签
- [ ] 每个数值都带**单位**和来源
- [ ] 数据缺失时页面显示 `—` 而不是白屏或报错
- [ ] 时间窗切换后**所有**图表和表格一起刷
- [ ] 没有直接读别人板块的数据（走接口）
