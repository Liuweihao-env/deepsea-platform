### 1.4 数据来源标签的取值（**纪律 4，不许省**）

> 🔴 **本节已被 2026-10-09 会上定推翻（原文保留作历史）**：**全平台删除来源字样 + 数据质量标记**
> （**视频素材例外**，视频仍须标出处）。`components.js` 的 `SourceTag` 已于 2026-10-15 删除。
> 下面「纪律 4 不许省」是 10-05 前口径。

每个页面顶部必须显示来源标签，取值只有这 4 个：

| 标签 | 含义 | 样式 |
|---|---|---|
| `真实数据` | 来自真实设备/老师提供的数据 | 绿色 |
| `公开数据` | 来自公开数据集（TFBID / DeepFish / NOAA NDBC） | 蓝色 |
| `仿真数据` | 程序生成 | 橙色 |
| `演示数据` | 手工准备、用于演示 | 灰色 |

> **多个来源并存时全部列出**，例：`公开数据 · 仿真数据`。
> **主动标出来源是加分项** —— 用假数据装成真的，才是答辩时最容易被戳穿的事。

## 三、通用组件（我做，你不用重复做）

> **每个组件分三部分写清：放什么字段 / 有哪些状态 / 怎么交互。** 状态没写全，就会出现"数据断了页面白屏"。

### 3.1 数值卡 `StatCard`

| 项 | 内容 |
|---|---|
| **放什么** | 指标名（小字）· 当前值（大字）· **单位** · **数据来源标签**（小字） |
| **状态** | ① 正常 ② 数据缺失（值显示 `—`，灰色，右上角标"设备离线"）③ 可疑（值显示为黄色，悬停提示"疑似异常"）④ 过期（值变灰，显示"最后更新 12:03:45"） |
| **交互** | 悬停显示：完整字段名、更新时间、数据来源 |
| **不许省** | **单位**和**来源标签** —— 单位错一次三个板块一起错 |

![图 2　数值卡 StatCard 的字段与排布：指标名 / 当前值+单位 / 数据来源](组件图-数值卡.png)

### 3.2 时序曲线卡 `TimeSeriesChart`

| 项 | 内容 |
|---|---|
| **放什么** | 标题 · 坐标轴（X 时间 / Y 数值 + 单位）· 曲线（可多条）· 图例 · 阈值参考线（可选） |
| **状态** | ① 正常 ② 无数据（显示"暂无数据"占位，不要白屏）③ 只有单点数据（显示散点而非折线） |
| **交互** | 悬停显示该点数值与时间；点击图例可隐藏/显示某条曲线；支持框选缩放（可选） |
| **异常标记** | 可疑点在曲线上**叠加红色圆点**，与明细表的"风险等级"对应 |
| **实现建议** | ECharts `line` + `markPoint` 做红点 |

### 3.3 事件列表 `EventList`

| 项 | 内容 |
|---|---|
| **放什么** | 时间 · 事件类型 · 简要描述 · **等级色标**（正常/注意/风险 或 蓝黄橙红） |
| **状态** | ① 正常 ② 空列表（显示"暂无事件"）③ 加载中（骨架屏） |
| **交互** | 点击条目展开详情；分级筛选；**支持"查看触发依据"跳转**（追溯用） |
| **注意** | 这是**告警中心与各板块共用的组件** —— 你先按这个做，将来告警中心直接复用 |

### 3.4 时间窗切换器 `TimeRangePicker`

| 项 | 内容 |
|---|---|
| **放什么** | 快捷项：`当前` / `1 小时` / `6 小时` / `24 小时` + `自定义`（选年月日范围） |
| **状态** | ① 默认选中"当前" ② 自定义范围非法（结束早于开始）时禁止提交并提示 |
| **交互** | 切换后**所有**图表与表格同步刷新（不要只刷一张图） |

### 3.5 数据来源标签 `SourceTag`

> 🔴 **2026-10-09 会上定：本组件已删除**（全平台删除来源字样 + 数据质量标记，视频素材例外）。
> `components.js` 的 `C.SourceTag` 已于 2026-10-15 移除。以下组件说明保留作历史。

| 项 | 内容 |
|---|---|
| **放什么** | 文字标签，取值见 1.4；多个来源全部列出 |
| **状态** | ① 单一来源 ② 多来源并列 |
| **位置** | 页面顶部（全局）+ 每个数值卡内（单指标） |

### 3.6 状态色阶 `StatusColor`（统一色彩语义）

| 语义 | 颜色 | 用在哪 |
|---|---|---|
| 正常 / 良好 | 绿 `#166534` | 状态灯、明细表标记 |
| 注意 / 可疑 | 黄 `#92400E` | 预警黄色级、可疑数据点 |
| 风险 / 故障 | 红 `#991B1B` | 红色预警、故障、异常点 |
| 信息 / 蓝色级 | 蓝 `#2F5496` | 蓝色预警、主色 |
| 无数据 | 灰 `#6B7280` | 缺失、禁用、离线 |

> **四级预警（蓝/黄/橙/红）按此扩展**：橙用 `#C2410C`。

### 3.7 细分组件（按需）

| 组件 | 用途 | 归谁用 |
|---|---|---|
| 数据明细表 `DataTable` | 秒级时间 + 站点 + 全指标 + 来源 + 质量等级 | 鱼类、环境 |
| 站点切换器 `SiteSwitcher` | 多站点切换 | 鱼类、环境、结构安全 |

**落点**：`app.js` / `app.css` 挂一次；图片文件与图源记录放同一目录。

### 8.2 全局「当前网箱」机制

> **全局只存一个"当前网箱"，切一次所有页面跟着变。**

**实现**：`window.CurrentCage` 单例（`app.js`）

| 接口 | 作用 |
|---|---|
| `CurrentCage.get()` | 取当前 `cage_id`（缺省 `cage_01`） |
| `CurrentCage.set(id)` | 切网箱：写存储 → 通知订阅者 → 派发事件 → `API._bump()` 让所有页面重算 |
| `CurrentCage.cage()` / `.site()` / `.siteName()` | 取当前网箱对象 / 所属 `site_id` / 站点中文名 |
| `CurrentCage.cages()` | 网箱列表（按 `cage_id` 排序，界面稳定显示「1 号 \| 2 号」） |
| `CurrentCage.subscribe(fn)` | 订阅切换，返回取消订阅函数 |

**兼容层（必须同时写，否则会出现"顶栏切了、新打开的页面没切"）**：

1. `window.__currentCage` = 当前 id；
2. `localStorage['deepsea_cage']` = 当前 id（`ai.js` 有 6 处在 `data()` 里读它做初始值，只派事件不够）；
3. 派发 `cagechange` 自定义事件（`detail.cage` = 当前 id）；
4. 主存储键用 `deepsea.currentCage`；首次启动时若只有旧键 `deepsea_cage`，自动迁移。

**取数规则**：

- 页面**不许各自存网箱状态**，一律读 `CurrentCage`；
- 后端接口带 `cage_id`（如 `/api/struct?cage_id=...`，非法值返回 404）；
- **环境页默认跟随当前网箱**（1 号→嵊山 `site_04`、2 号→小麦岛 `site_03`）；顶部站点按钮**保留**，
  手动切站要**标清「查看其他海域」**且**不改当前网箱**；
- 🆕 **2026-10-27**：站点按钮 / 站点目录表**显示顺序统一**为 嵊山（`site_04`）→ 小麦岛（`site_03`）→
  仿真演示站点（`site_01`）→ 芝罘岛（`site_02`）→ 遮浪（`site_05`），与 `/api/sites`、`farm.json` 同源；
- 环境数据**永远来自真实台站**，"当前网箱"只决定**用哪片海的数据**，**绝不往台站里塞模拟值**。
