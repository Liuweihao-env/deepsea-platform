# docs/ —— 冻结文档快照

**这里放的是快照，不是正本。**

## 为什么是快照

项目里有一条规矩（`协作/协作规则.md`）：**任何文件都只有一个作者。**

文档的正本在**仓库的上一级目录**（`C:\Users\38793\Documents\比赛\`），由**队长维护**。
如果这里也直接编辑，就会出现两份都活着、内容却不一样的文档 ——
而 `项目通用规范` 第一条就是 **"同一个东西不许起两个名字"**，文档同理。

所以：**改文档 → 改上级目录的正本 → 跑同步脚本 → 提交。**

## 怎么同步

```powershell
pwsh scripts/sync_docs.ps1
```

脚本会把正本复制到本目录，并打印每个文件的同步时间。
