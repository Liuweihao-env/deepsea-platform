## 解读与限制

冬季低温与夏季高温应分月观察。长时间越线可能反映季节性生理胁迫，不能为了演示改观测值、鱼种或阈值。本表是已有鱼种阈值的历史暴露率，不是独立告警事件数、死亡概率或适养推荐；一段持续越限可对应许多逐时点。全期包含入库缺口，不能当完整年度的时间占比。
运行时口径：已核对 mock.js 的 API.ruleCheck 与 server.py 的 Platform.rule_check，均按站点主养鱼种的四线判定，高温采用 ≥、低温采用 ≤，红色优先于黄色；本统计与两箱现行判定边界一致。逐样本越线率仍不等于实际生成、合并、确认的告警条数。
