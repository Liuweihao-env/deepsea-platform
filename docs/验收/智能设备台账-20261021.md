## 范围

1. **正式设备台账**：`data/farm.json` 两箱各 7 台（水温 / 溶氧 / 倾角 / 锚链张力 / 投饵 / 补光 / 网衣绞车），同型各一套、编号唯一、`cage_id` 归属明确。
2. **`device_name_cn`**：14 条设备记录全部补齐；界面主显示中文名，`device_id` 只留详情 / 悬停。
3. **两箱设备归属**：`cage_01` 设备在 `site_04`，`cage_02` 在 `site_03`；`/api/farm/devices?cage_id=` 与 `/api/devices?cage_id=` 均按箱过滤。
4. **后端指令隔离**：命令写入 `cage_id`；`/api/commands?cage_id=` 过滤；跨箱下发 400、未知设备 404、设备类型不匹配 400。
5. **闭环**：两箱投喂 / 补光 / 起重均走同一套后端状态机；失败进告警中心，告警带 `cage_id`，`alarm_type=command` 只点亮智能入口红点、不进总览三张板块卡。
6. **出处不编造**：1 号箱 6 台沿用既有台账；2 号箱 6 台与两箱网衣绞车标 `provenance=pending_confirmation`，页面显示「待确认」，不写具体厂商 / 证书 / 型号。
