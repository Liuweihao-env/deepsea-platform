## 零、颗粒度标准

> **一个任务 = 半天到两天能干完 + 有一个别人能验收的产出物。**

判断标准：**说不出"做完之后拿什么给别人看"，那它就不是任务，是一件事。**

## 二、先打通一条竖线（不要八包并行）

```
海水温度（仿真数据）
   → 接口取到
   → 网页上画出一条曲线
   → 越过阈值
   → 出一条告警
   → 点开看得到"哪条数据触发的、命中了哪条规则"
```

**这条竖线通了，架构就被证明是活的**，剩下都是照这个模式扩。
**如果 11-14 前什么都来不及，这条竖线本身就是能演示的最小产品。**
